Use with Claude or ChatGPT

Add Deseret MCP to your AI assistant once, then ask in plain language. It is free and needs no account.

Deseret MCPhttps://mcp.deseret.wiki/api/mcp

Which AI do you use?

Before you start

  • Do this on a computer, in the Claude app or at claude.ai. It carries over to your phone.
  • The free plan allows one custom connector.
  • On a work or school account, only an admin can add connectors.
  1. 1

    Open Customize

    In the sidebar on the left, click Customize.

  2. 2

    Choose “Add custom connector”

    Click the Connectors tab, then the + Add button, then Add custom connector.

  3. 3

    Name it and paste the address

    Type Deseret in the first box. Copy the address below and paste it into the second box. Then click Continue.

    https://mcp.deseret.wiki/api/mcp
  4. 4

    Leave “No sign-in” and click Add

    Claude checks the address and picks No sign-in for you. That is correct: the tools are free and need no account. Don’t change anything else, then click Add.

    A yellow warning appears for every connector that has no sign-in. It doesn’t mean anything is wrong.

  5. 5

    Check it’s switched on

    Start a new chat. Click the + below the message box, then Connectors. The switch next to Deseret should be on. It usually already is, and it stays that way for new chats.

Before you start

  • Custom connections need a ChatGPT plan that allows them; if you don’t see Plugins, your plan or workspace may not.
  • Do this on a computer, at chatgpt.com.
  1. 1

    Open Plugins

    In the sidebar on the left, click Plugins.

  2. 2

    Choose “Add custom MCP server”

    Click Add in the top-right corner, then Add custom MCP server. MCP is just the technical name for this kind of connection.

  3. 3

    Fill in the form

    Work down the form from top to bottom:

    1. Name: type Deseret. Leave Description empty.
    2. Connection: paste the address below.
    3. Authentication: change OAuth to No authentication.
    4. Tick I understand and want to continue.
    5. Click Create as a plugin.
    https://mcp.deseret.wiki/api/mcp

    The step people miss is Authentication. It starts on OAuth. If you leave it there, ChatGPT will ask you to sign in somewhere and fail. Pick No authentication.

  4. 4

    Click “Connect Deseret”

    ChatGPT checks the address for a few seconds and then asks you to confirm. Click Connect Deseret. A green message says it is now connected, and a new icon appears under Installed.

  5. 5

    Ask for it by name

    Say “use Deseret MCP” in your message. To be sure it’s used, type @ and the first letters of the name and pick it from the list.

If something goes wrong

“Add custom connector” is greyed out

Custom connectors need a paid plan or an admin on work and school accounts. On a free Claude plan you get one custom connector, so remove another one first.

It says a connector with this address already exists

It is already added. Open Connectors and make sure the switch next to Deseret is on.

ChatGPT asks me to sign in, or the plugin won’t connect

Set Authentication to No authentication before you create it. If you already created it with OAuth, delete it and add it again.

The Deseret letters show as boxes

Your device has no Deseret font. Install one from the Deseret Wiki’s font page; Noto Sans Deseret is a good start.

The AI answers without using the tools

Name it in your question (“use Deseret MCP”) and check the connector is switched on for the chat. In ChatGPT, type @ and pick it from the list.

What can this connection see?

Only the text you ask it to transliterate, and only while it does so; nothing is stored. The wiki answers come from the public pages of deseret.wiki. It never sees your account or your other chats.

On your own computer

The same server runs locally with Node.js 20 or newer and nothing else to install. Locally it can also transliterate whole files (deseret_file), writing name.dsrt.md beside the original. Setup is in the README on GitHub.

claude mcp add deseret -- node <repo>/bin/deseret-mcp.mjs

Other tools

Claude Code: run this once in a terminal.

claude mcp add --transport http deseret https://mcp.deseret.wiki/api/mcp

Apps that only speak stdio can use mcp-remote, or the local server:

{
  "mcpServers": {
    "deseret": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://mcp.deseret.wiki/api/mcp"
      ]
    }
  }
}

What it can do

  • Write any English in the Deseret Alphabet.
  • Explain a word letter by letter.
  • Read Deseret back into Latin letters.
  • Answer questions from every source on deseret.wiki, with links.
  • Say plainly which words it could not spell.
