# Urim

- Evidence comes only from Church-published translations (see README sourcing rule). Never add a rendering from general knowledge; never use `ai_generated` rows.
- Pulpit's `Unverified` glossary rows are not imported.
- Served at https://samuelbaird.com/urim (monorepo `sites/urim`). Pages carry `<!--family:*-->` markers; after every pipeline build run `node scripts/family-sync.mjs` at the repo root, which stamps the shared sidebar/header/colophon and prefixes root-relative links with `/urim`. Style guide: `packages/family/STYLE.md`.
- Site is plain static HTML/CSS/JS on Vercel (`site/` is the root); no front-end build step. Python builds data/pages.
- Do not modify `../../../pulpit-vault` (outside this repo); read-only input.
- Hosted MCP tools live in `src/mcp-core.mjs` (ESM), shared by `api/mcp.js` (Vercel, CJS wrapper reading data from disk) and `src/worker.mjs` (Cloudflare). Change tools there, not in the wrappers. `npm test` runs the Node tests (`deseret/test`, `tests/mcp.test.mjs`); Python tests are separate (pytest).
- Hosting: Cloudflare Worker `urim` (`wrangler.jsonc`), reached at samuelbaird.com/urim via the samuelbaird-com service binding and at urim.samuelbaird.com (custom domain). `site/` is Workers static assets; only `/mcp`, `/api/*`, `/urim` and `/urim/*` run the Worker (MCP plus the `/urim` prefix rewrite, keeping `/urim` on asset redirects). Data is bundled (`data/api.json`, `deseret/data/*`, `words.tsv` as a Text module); the word list is parsed at startup. The old-host 301 (urim.samuelbaird.com -> samuelbaird.com/urim, except `/urim*` and `/api/*`) is in the Worker but only runs for those paths, so the zone has a Single Redirect rule `urim-legacy-host` doing the same for every other path. `npm run cf:dev` / `npm run cf:deploy`. No env vars or secrets.
