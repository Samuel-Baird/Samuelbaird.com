# Changes in prophetic teachings without clear mechanisms for correction

## General response

This file is the epistemic/procedural companion to
`prophetic-fallibility-versus-prophetic-authority.md` — collect the
concrete case list here rather than re-arguing the framework: Adam-God
(`adam-god-teachings.md`), blood atonement rhetoric
(`blood-atonement-rhetoric.md`), racial priesthood-restriction theories
(`past-prophetic-explanations-for-the-racial-restriction.md`),
Kinderhook Plates (`kinderhook-plates.md`), and the November
2015/2019 LGBTQ policy reversal (`lgbtq-teachings-and-policies.md`) are
all documented cases where a later leadership generation reversed or
disavowed an earlier one's confidently-taught position, generally
without a clearly articulated, generalizable rule for how or when such
corrections happen.

## Catholic and Protestant response

Ask what mechanism the interlocutor's own tradition uses to distinguish
binding teaching from later-correctable error, and whether that mechanism
is actually clearer in practice than the LDS pattern, or only clearer in
principle (formal categories like ex cathedra infallibility exist, but
are rarely invoked, so most Catholic doctrinal development in practice
also proceeds through gradual consensus-shift rather than the formal
mechanism, similarly to the LDS pattern).

## Exmo/atheist response

Don't minimize this one — it's a legitimate, well-evidenced structural
critique. State plainly: there is no publicly articulated, consistently
applied rule members or outside observers can use in real time to
predict which current teachings will later be treated as correctable
error versus permanent doctrine — corrections have so far only been
identifiable in hindsight, after a later leadership generation acts. This
is a genuine, unresolved problem for the Church's model of continuing
revelation, not something the individual case-by-case apologetic
responses in the other files fully dissolve when taken together.
