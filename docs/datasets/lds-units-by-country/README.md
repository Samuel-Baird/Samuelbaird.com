# LDS units by country

Ward and branch counts and membership per country, used by the Activity Estimator (Data Explorer > Tools).

- `units-by-country.json`, `country-stats.json`, `continent-stats.json`: the Church's facts-and-statistics figures for 2025 (learn site plus the Newsroom, which covers ~40 more countries). Generated by `scripts/church-facts-statistics/build_country_stats.py`; do not edit by hand.
- `activity-baselines.json`: self-identification / membership ratios from surveys or censuses. Optional per country.
- `handbook-thresholds.json`: General Handbook ch. 36 minimums for creating units.

Caveats: not everyone in a unit is active; large units may choose not to split; fast-growing countries split early so units run small. Handbook figures are creation minimums, not averages.
