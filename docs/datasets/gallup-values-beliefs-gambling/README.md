# Gallup Values and Beliefs: gambling by religion

One chart, `gallup-acceptable-by-religion.json`: share of U.S. adults saying
gambling is morally acceptable, by religion, May 2001-2016 pooled (n = 16,754;
295 Mormons, about +/-7 pts).

Source: Gallup, "U.S. Religious Groups Disagree on Five Key Moral Issues"
(https://news.gallup.com/poll/191903/religious-groups-disagree-five-key-moral-issues.aspx).
Values are transcribed from Gallup's published table, not computed from
microdata. Gallup labels the groups "No religion" and "Mormon"; the chart uses
"Unaffiliated" and "Latter-day Saint". Render:
`scripts/gallup-values-beliefs-gambling/render_gallup_acceptable_by_religion.py`.
