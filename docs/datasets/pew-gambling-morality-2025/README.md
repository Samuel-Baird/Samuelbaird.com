# Pew 2025: the morality of gambling

Two charts from Pew's Spring 2025 Global Attitudes work. Neither breaks out
Latter-day Saints; they give context for the Latter-day Saint figures in
`gallup-values-beliefs-gambling` and `next-mormons-survey-2016`.

- `gambling-morally-wrong-by-country.json`: all 25 countries, read from the
  chart in the report (https://www.pewresearch.org/religion/2026/03/05/in-25-country-survey-americans-especially-likely-to-view-fellow-citizens-as-morally-bad/).
- `us-gambling-wrong-by-religion.json`: U.S. adults by religion, from the
  short read (https://www.pewresearch.org/short-reads/2026/03/16/americans-are-less-likely-than-people-in-many-other-countries-to-see-gambling-as-morally-wrong/).

Values are transcribed from Pew's published charts and text. U.S. wording was
"morally wrong"; other countries used "morally unacceptable".

Flag images in `scripts/pew-gambling-morality-2025/flags/` come from flagcdn.com (320px PNGs, ISO 3166 codes) and appear beside each country label; bar colors are one color per flag.
