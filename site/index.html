Deseret MCP

Your AI assistant can write any English in the Deseret Alphabet, read Deseret back into Latin letters, and answer questions about the alphabet from every source on deseret.wiki, with a link to the page each answer came from. It is free and needs no account.

Addresshttps://mcp.deseret.wiki/api/mcp

Try it

This box uses the same server your assistant would. Words it cannot spell stay in Latin letters and are listed, never guessed.

What your assistant can do with it

Write in Deseret 𐑉𐐴𐐻

Single words, passages or whole files. Every word of the 126,052-word CMU Pronouncing Dictionary, spelled sound by sound the way deseret.wiki spells its own pages.

  • Explains a word letter by letter: name, sound, key word.
  • Lists the words it could not spell, and the ones it built from their parts.
  • Keeps Markdown and HTML intact: links, code, footnotes.
  • Reads Deseret back, naming the homophones.

Ask about the alphabet 𐐰𐑅𐐿

Answers come from what deseret.wiki holds, with the page to cite.

  • The encyclopedia article, section by section (23 sections).
  • The library: 28 PDFs, sermons and readings.
  • 35 fonts, 40 books & prints, 9 videos, 10 resources, 15 quotes.
  • The 38-letter chart with sounds and key words.

Things to ask

Name it in your question so the assistant knows to use it.

Use Deseret MCP: write "I will go and do the things which the Lord hath commanded" in the Deseret Alphabet, and tell me any words you could not spell.
Use Deseret MCP: who designed the Deseret Alphabet, and why was it abandoned? Cite the Deseret Wiki pages.
Use Deseret MCP: spell "Zarahemla" in Deseret and explain each letter.
Use Deseret MCP: which fonts can I install to type Deseret in Word, and what licence is each under?

The tools

ToolWhat it does
to_deseretEnglish text, up to 100,000 characters, to Deseret, with a report of unknown, built-up and two-sense words.
deseret_wordOne word explained: phones, each letter's name and sound, every pronunciation.
from_deseretDeseret back to Latin letters, naming homophones and respelled words.
search_wikiSearch every source on deseret.wiki; each hit links to its page and original source.
read_wikiThe full text of a hit with a ready-made citation.
wiki_contentsWhat the wiki holds, by kind.
deseret_fileLocal server only: transliterates a text, Markdown or HTML file on your computer.
