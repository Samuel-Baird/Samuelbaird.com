Which AI do you use?

Before you start

  • Do this on a computer, in the Claude app or at claude.ai. It carries over to your phone.
  • The free plan allows one custom connector.
  • On a work or school account, only an admin can add connectors.
  1. 1

    Open Customize

    In the sidebar on the left, click Customize.

  2. 2

    Choose “Add custom connector”

    Click the Connectors tab, then the + Add button, then Add custom connector.

  3. 3

    Name it and paste the address

    Type Urim in the first box. Copy the address below and paste it into the second box. Then click Continue.

    https://urim.samuelbaird.com/api/mcp
  4. 4

    Leave “No sign-in” and click Add

    Claude checks the address and picks No sign-in for you. That is correct: the data is free and needs no account. Don’t change anything else, then click Add.

    A yellow warning appears for every connector that has no sign-in. It doesn’t mean anything is wrong.

  5. 5

    Check it’s switched on

    Start a new chat. Click the + below the message box, then Connectors. The switch next to Urim should be on. It usually already is, and it stays that way for new chats.

Before you start

  • Custom connections need a ChatGPT plan that allows them; if you don’t see Plugins, your plan or workspace may not.
  • Do this on a computer, at chatgpt.com.
  1. 1

    Open Plugins

    In the sidebar on the left, click Plugins.

  2. 2

    Choose “Add custom MCP server”

    Click Add in the top-right corner, then Add custom MCP server. MCP is just the technical name for this kind of connection.

  3. 3

    Fill in the form

    Work down the form from top to bottom:

    1. Name: type Urim. Leave Description empty.
    2. Connection: paste the address below.
    3. Authentication: change OAuth to No authentication.
    4. Tick I understand and want to continue.
    5. Click Create as a plugin.
    https://urim.samuelbaird.com/api/mcp

    The step people miss is Authentication. It starts on OAuth. If you leave it there, ChatGPT will ask you to sign in somewhere and fail. Pick No authentication.

  4. 4

    Click “Connect Urim”

    ChatGPT checks the address for a few seconds and then asks you to confirm. Click Connect Urim. A green message says it is now connected, and a new icon appears under Installed.

  5. 5

    Ask for it by name

    Say “use Urim” in your message. To be sure it’s used, type @ and the first letters of the name and pick it from the list.

If something goes wrong

“Add custom connector” is greyed out

Custom connectors need a paid plan or an admin on work and school accounts. On a free Claude plan you get one custom connector, so remove another one first.

It says a connector with this address already exists

It is already added. Open Connectors and make sure the switch next to Urim is on.

ChatGPT asks me to sign in, or the plugin won’t connect

Set Authentication to No authentication before you create it. If you already created it with OAuth, delete it and add it again.

The AI answers without searching the data

Name it in your question (“use Urim”) and check the connector is switched on for the chat. In ChatGPT, type @ and pick it from the list.

What can this connection see?

Only the public, read-only atlas you can already browse on this site: Church renderings, usage counts and links. It never sees your account or anything you type into the site, and it does not translate or store your text.

Free local translator

Separately from this connection, Urim ships a translation server that runs entirely on your own computer: it caches translations, enforces the Church terminology above, and uses local models, so there are no paid APIs. It is for developers and researchers; setup is in the README on GitHub.

Other tools

Claude Code: run this once in a terminal.

claude mcp add --transport http urim https://urim.samuelbaird.com/api/mcp

Apps that only speak stdio can use mcp-remote:

{
  "mcpServers": {
    "urim": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://urim.samuelbaird.com/api/mcp"]
    }
  }
}

What it can do

  • Look up a term in English, Portuguese or Spanish, including reverse lookup.
  • Show every Church rendering with usage counts, years and source links.
  • Pick out the Church terminology in a passage you are translating.
  • List terms the Church renders inconsistently.
  • Show the earliest attested use of a term, in English and in official translations.
  • Write English text in the Deseret Alphabet.
